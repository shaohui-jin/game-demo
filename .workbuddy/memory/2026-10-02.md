### 关键实现决策（下一轮别推翻）
1. **拖拽位移直接写 DOM style，不走响应式**。否则每帧 pointermove 都会触发整块棋盘的 vnode diff。
2. **BoardCell 刻意不绑 `transform`**。拖拽靠 `el.style.transform` 直写，若 Vue 也绑 transform，style patch 会把它擦掉。
3. **`:ref` 放在子组件上拿到的是组件实例（`$el` 才是根元素）**，不能直接当 HTMLElement 用。GameBoard 的 `setCellEl()` 里做了拆包。
4. **store 的 `board` / `web` computed 必须返回定长数组**（`new Array(TOTAL).fill(...)`），否则未 init 前 `web[i]` 是 undefined，触发 "Expected Boolean, got Undefined" 的 prop 警告。
5. 粒子 canvas 用 `attachCanvas/detachCanvas` 在组件 mount/unmount 时挂载，避免 rAF 泄漏。
6. `#app` 这个 id 仍由 index.html 提供，同时承担竖屏布局容器与屏幕震动载体两件事。

### 修掉的一个真实 bug（P0 原型同样存在）
`defOf(k, lv)` 在 P0 里写成 `if (!t) return null`，于是**任何 `lv > items.length` 都会静默返回顶端定义**。
后果：越界的孤儿物品（如 `{c:'toy', l:99}`）会被 `load()` 判定为"合法"而保留，渲染成"顶端造型 + 错误等级数字"。
已改为精确匹配 `lv !== items.length + 1 → null`。这条是纯逻辑测试抓出来的。

### 环境坑（下次别踩）
`rm` / `rm -rf` 在这个沙箱里会被 **SIGTERM 中途掐断**（一个 `rm -f a b c d` 只删掉第一个文件就退出，exit -1）。
删多文件要么逐个删并逐个校验，要么改用 PowerShell `Remove-Item -LiteralPath ... -Recurse -Force`（注意 PowerShell 工具不回传 stdout，验证要用 Glob）。

另一个同类坑：**长命令必须显式给 timeout**。`npx vitest run | tail` 这种管道在某些时候会跑超默认 120s 被 SIGTERM 掐掉（全量套件最慢见过 88s）。改成 `> 日志文件 2>&1` 再读文件，并显式传 `timeout`。

### 几条要记住的设计约束
- **装饰不产生任何数值收益**（文档 6.2 硬约束）。代码里**故意不加**"装饰加成"字段，并有一条单测锁住它。装饰的价值是把审美投入变成沉没成本。
- **区域必须顺序解锁**，`canUnlockRegion` 显式挡跳级；**解锁后立刻重抽订单**，否则新档位要等最长 8h 才出现。
- **常驻宠物离线结算的 `petAt` 推进方式**：未达上限 `+= 已结算小时数`（留住零头）；**已达上限直接推到 now**（上限外的时间彻底作废）。混用会让同一段时间被反复结算 —— 有一条单测专门盯这个"重复发钱"bug。
- **好感度在顾客转化为常驻宠物后不再累积**，否则数字失去意义、也掩盖"已转化"这个事实。
- **体力上限一律走 `staminaMax(s)`**，不要直接读 `STAMINA_MAX`，否则洗护区/餐厅加成失效。

### 用户原话 → 落实

1. **「只有背包存在解锁格子，正常游戏区域不存在解锁格子这一说」**

2. **「玩具架、玩具箱应该是在主场景里常驻的母体，可以放到背包里」**
   → 新增**设施链 `fac`**（Lv1 玩具架 → Lv2 玩具箱）。设施不是新对象类型，而是"一个可点击的链物品"，
   于是拖拽/背包/存档/渲染/特效全部复用既有机制。开局自动占两个棋盘格；2 个玩具架可合成 1 个玩具箱。
   `SpawnerBar.vue` 与 `BackpackModal.vue` 删除。
3. **「物品可以从格子拖拽到背包里面，背包中的物品点击就可以放到主场景格子里」**
   → `useDrag` 落点扩成 `board` / `bag` 两种 zone；背包从**全屏弹窗改成底部抽屉**
   （全屏遮罩会盖住棋盘，拖拽的起点根本看不见 —— 物理上做不到）。
   抽屉高度靠 CSS 变量 `--bag-h` 压缩棋盘（写在 App 的 `.screen` 上，`.board` 作为后代继承）。
4. **「母体是释放了一定数量才会冷却，不是点一次冷却一次」**
   → `ClickSpec` 从 `charges` 改成 `buffer`（储备上限）+ `refillMs`（耗尽后冷却）+ `exhaust`（耗尽行为）。
   点第 1 次**不进冷却**，储备归零才盖冷却遮罩，到点由 `tickGenerators()` 在每秒 tick 里补满。
5. **「链路看不出来，需要图鉴显示链路图；母体不一定是点完就没了，部分冷却、部分释放完生成另外的道具」**
   → `ChainTreeModal` 重写为**图鉴**：横向链路图 + 三色图例（冷却型/转化型/消失型）+ 每个可点击节点的产出与耗尽行为。
   链路语义（改 `chains.ts` 即可）：玩具架/玩具箱/美容台 = 冷却型；**猫城堡 → 伴手礼**、**豪华礼盒 → 玩具架** = 转化型；
   链中段 Lv3（铃铛球/洗澡球/鲜鱼排）= 消失型。

### ★ 顺带修掉的两个真 bug（都属"存档杀手"级别）

1. **`countFacilities()` 能让整份存档加载失败**：它被 `ensureFacilities()` 从**存档归一化流程**调用，
   而那是老存档进来时的第一站 —— 此时 `s.bag` 可能不存在（旧版没有背包）。
   `for...of s.bag` 抛 `TypeError: s.bag is not iterable`，异常冒到 `load()` 外面。
   已改为对残缺 state 免疫 + 补回归测试。
2. **`ensureFacilities()` 位置错**：原来在背包归一化**之前**，导致"设施全收进背包"的玩家每次读档被重复补发设施。已后移。

另外堵了一个设计漏洞：**背包会变成跳过冷却的漏洞** —— 冷却中的设施塞进背包再拿出来，若只搬不挂起冷却就白拿补满。
新增 `cdLeft` 字段挂起剩余冷却（`suspendCooldown` / `resumeCooldown`），有单测锁住。

### 设施保护（我加的设计）
**禁止蛛网牺牲设施** —— 设施是唯一产出源，吃掉最后一个会让玩家进入"什么都产不出"的死局。
另加 `ensureFacilities()` 兜底：棋盘 + 背包一个设施都没有时补回开局设施。

## 视觉改版：手绘贴纸风（本轮主要工作）

用户先问「UI 贴图怎么生成 / 用什么形式实现类似肥鹅的 UI」。**先纠正一个前提：工程里 SVG 用量为 0**
（`grep -c "<svg" src` → 0）。当前视觉实现是 **emoji 字形 + CSS 上色**（chains.ts 的 emoji 字段 + BoardCell 直接 `{{ def.emoji }}`）。

### 结论：走「位图贴图 + 九宫格」，并按元素分工
- 面板/按钮/气泡 → **9-slice**（换皮不换布局的关键，组件结构一行不用改）
- 物品/发射器/货币 → 透明底 sprite
- SVG 只保留在纯色线性图标上；是分工，不是全盘替换
- **emoji 的问题**：三端字形不一致、无法改色改描边、天然扁平 —— 做 P0 占位行，做成品必死
- **纯 SVG/CSS 的问题**：肥鹅那套观感靠厚描边+内阴影+高光釉面+柔投影+噪点，手写代价极高

### 风格裁定过程
先选「低饱和治愈系」→ **用户中途改选「手绘贴纸风」**，最终以此为准。

  好处：新增贴图不用改代码；写错键在构建期暴露；**切 webp 只需丢文件进去，一行代码不改**
- `src/ui/SpriteIcon.vue` —— 三级降级：贴图 → 图片加载失败 → emoji 兜底

### ★ 三条踩出来的技术要点（改这块先看）
1. **贴纸错位必须用 `rotate` 属性，不能用 `transform: rotate()`**。
   useDrag 直接写 `el.style.transform` 做拖拽位移，旋转挂 transform 上会被擦掉（拖一下角度就没了）。
2. **模切白边用 `border` 实现，不要用 box-shadow / outline**。
   三者是独立属性：border 扛白边（永不被状态覆盖），outline 扛母体/中段/任务物的描边语言，
   box-shadow 扛落影与状态光。否则 `.item.sel` / `.item.glow` / `.item.fin` 一覆盖 box-shadow，
   白边就跟着没了。
3. **纸张噪点做成 body 的静态背景层，不要用全屏 `mix-blend-mode: multiply` 叠加层** ——
   后者会让每一帧都做整屏合成，中低端安卓必掉帧。
4. `tsconfig.app.json` 的 `types` 需加 `"vite/client"`，否则 `import.meta.glob` 报类型错。

typecheck 干净 / 120 例单测全绿 / build 通过 / 真机截图确认棋盘与背包的贴纸观感。
