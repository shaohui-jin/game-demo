# 《爪爪乐园》整体 UI 重设计 · Phase 1 需求摘要

> 产出：需求发现分析师 许明需 ｜ 2026-10-21 ｜ 用户四问全部已回答

## 用户四问答复（原始记录）

1. **视觉方向**：「都做一版看下」→ 四方向各出一版对比（软糯黏土 3D / 现代插画扁平 / 水彩手绘治愈 / 精修贴纸风）
2. **重设计范围**：整体焕新 = UI 框架 + 全部 84 个贴图
3. **IP 气质**：软萌治愈（锁定为共用的基调）
4. **保留项**：无，现有系统全推翻

## 五要素

| 维度 | 结论 |
|---|---|
| 场景 | 竖屏手机网页（max-width 460px，单屏无滚动）的猫狗合成+模拟经营手游 UI 全集重设计：顶部双行 HUD（金币/钻石/体力/星星/等级）+ 功能栏（订单/经营/商店/背包/去乐园）+ 7×9 合成棋盘（物品/蛛网/发射器耐久角标）+ 底部信息栏 + 8 类弹窗（订单/商店/充值/设置/背包/合成树/经营）+ 乐园场景页（9 区域解锁/装饰摆放/摄影棚）；PWA 可安装，后续可能打包安卓 APK |
| 受众 | 《肥鹅健身房》玩法对标受众——休闲治愈向合成经营玩家，猫狗宠物爱好者，偏女性向；单机无联机；含充值入口 |
| 调性 | 软萌治愈（锁定基调）——暖色柔光、低明度冲击、亲和造型；渲染方向要求多版对比：① 软糯黏土 ② 插画扁平 ③ 水彩手绘（④ 精修贴纸风经彩格调裁定排除：用户已明言"现有系统全推翻"，精修贴纸=把被否决的旧方向重做一遍，逻辑矛盾） |
| 品牌 | 原创品牌，100% 原创美术红线（禁止任何对标游戏素材）；旧贴纸风（#fbf1dd + 波点噪点 + 胶带）不保留；技术栈 Vue3 + TS + Pinia + Vite，贴图走 src/assets/sprites 资源键系统 |
| 规模 | 复杂度高：UI 框架（HUD/棋盘/8 弹窗/乐园页）+ 84 项 SVG 贴图全部重绘（10 条合成链 4-8 级物品、8 种猫狗顾客、11 件装饰、14 个功能图标、5 种道具、9 个区域、乐园底图） |

## 核心诉求（显性化）

用户原话「现在的 ui 贴图都很丑」——从框架到素材的**整体视觉翻新**，非局部优化。

## 执行策略（成本控制）

先出「关键界面样张」对比轮：每方向 1 屏同构图主界面（HUD + 7×9 棋盘 + 底部栏）+ 色板/质感/贴图试样，保证变量只在色/形/质感；用户选定方向后再进入全套 84 贴图 + 全部界面深化。

## 硬约束

1. 原创红线：不可使用任何对标游戏素材
2. 7×9 棋盘必须完整落首屏，单屏无滚动
3. 84 项贴图须替换进现有资源键，Vue 现有逻辑零改动接入
4. 8 类弹窗需组件化规范统一
5. 中低端安卓性能敏感：禁全屏 mix-blend 合成层；动画只碰 transform/opacity
