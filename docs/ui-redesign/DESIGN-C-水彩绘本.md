## 0. 方向声明

**C 是什么**：一本摊开的猫狗绘本——奶白纸底、湿边水彩、炭铅轮廓、衬线标题。所有 UI 元素都是「贴在纸面上的手绘物」，不是玻璃、不是塑料、不是金属。

**C 不是什么**（三条禁令，划清与被否决的旧贴纸风的边界）：
1. 不是旧贴纸风返祖：禁模切白边、禁硬落影、禁和纸胶带标题条
2. 不是滤镜驱动的水彩：运行时禁 `feTurbulence`，晕染与纸纹一律预渲染
3. 不是暗色/高科技：禁玻璃拟态、禁霓虹发光、禁渐变按钮

**风险与对策**（选定 C 的前提认知，不回避）：

| 风险 | 对策 |
|---|---|
| feTurbulence 在中低端安卓致命 | 晕染/纸纹全部预渲染 webp，SVG 只出干净几何 |
| 84 张贴图工时 +35%，每张双版本 | 先玩具链 8 张试点，验证管线与性能后再铺开 |
| 衬线字体落地不可控 | 系统栈降级 + 常用字子集化 + 小字号避用衬线 |

## 1. 色彩系统

### 1.1 纸面与墨色（框架层）

| 角色 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 纸底 | `--surface` | `#FBF4E6` | 屏幕底色 |
| 卡面 | `--card` | `#FFFDF7` | HUD 芯片、按钮、弹窗 |
| 棋盘底 | `--surface-2` | `#F1EDE2` | 棋盘容器 |
| 空格 | `--cell` | `#FAF7EE` | 棋盘空格 |
| 格线 | `--grid-line` | `#E4DCCC` | 空格细圈 |
| 主墨 | `--ink` | `#4F4235` | 正文、等级牌底 |
| 次墨 | `--ink-2` | `#97836D` | ≥14px 辅助文字、图标 |
| 弱墨 | `--ink-3` | `#BFB3A0` | 锁、占位、装饰 |
| 炭铅 | `--pencil` | `#B98A5E` | SVG 内手绘描边 |
| CTA | `--cta` | `#4A463E` | 主按钮（石板灰、微圆角矩形） |
| 纸边白 | `--paper` | `#FFFFFF` | 衬纸边 |

对比度自检：`--ink` on `--surface` ≈ 8.4:1（AAA）；`--ink-2` on `--surface` ≈ 3.1:1——**仅限 ≥14px 或非关键信息**。信息栏合成教学文案必须用 `--ink` 600 字重，禁用 `--ink-2`（严过审评审教训）。

### 1.2 功能色（资源）

| 资源 | 令牌 | 值 | 色名 |
|---|---|---|---|
| 金币 | `--gold` | `#C9A24B` | 芥末黄 |
| 星星 | `--star` | `#E5C07B` | 麦金 |
| 钻石 | `--gem` | `#1E2A38` | 墨黛蓝 |
| 体力 | `--energy` | `#9DBBD4` | 雾蓝 |
| 警告/红点 | `--warn` | `#C9603F` | 锈红 |
| 成功 | `--ok` | `#6FBF73` | 苔绿 |

金币与食物链（麦金 #E5C07B）明度差 ≥2 档，解决「金币与食物贴图同色」的撞车；体力（雾蓝）与护理链（鼠尾草 #9CB380）色相完全分离。

### 1.3 状态色语言（三套共享，C 不例外）

可合成 `#6FBF73` ｜ 选中 `#3A6EA5`（群青，C 专属微调）｜ 可存背包 `#6FC0E8` ｜ 可献祭 `#9B6BD6` ｜ 可挤出 `#F2A03D`

铁律：落点四色三方向完全一致，玩家扫读习惯不变；选中色可与主色联动，但必须与「可存背包」可分辨——C 的群青 `#3A6EA5` 比天蓝 `#6FC0E8` 深 3 档明度，14px 色块下可辨。

### 1.4 链色阶梯（核心四条）

`chains.ts` 的旧 `bg/fg/fx` 字段不再驱动 tile 背景（由 CSS 变量接管，字段保留作为兜底与 M0 参考）。新阶梯：

| 链 | 色相 | Lv1-2 浅档 | Lv3-5 中档 | Lv6-8 深档 | 纸浸 soft |
|---|---|---|---|---|---|
| 玩具 toy | 干玫瑰 | `#E7CBCB` | `#D3A0A2` | `#B88284` | `#F4E7E7` |
| 护理 care | 鼠尾草 | `#C2D3B3` | `#9CB380` | `#7F9765` | `#EBF0E4` |
| 食物 food | 麦金 | `#F2DDB4` | `#E5C07B` | `#C7A25E` | `#F8F0DD` |
| 设施 fac | 陶土 | `#DDA98D` | `#C87A5A` | `#9E6242` | `#F6E6DB` |

其余六链（礼包/舒适/训练/医疗/清洁/货币）在 M3 铺开阶段按同公式分配色相槽，候选：舒适→雾蓝 `#9DBBD4`、货币→芥末黄 `#C9A24B`、训练→深苔 `#7F9765`、礼包→灰紫 `#B7A8C4`、医疗→青灰 `#8FA8A0`、清洁→薄荷灰 `#A8C4B8`。**候选必须通过「一眼辨链」测试才允许定稿**：同屏任意两链明度差 ≥15%、色相差 ≥25°。

## 2. 字体排印

| 层 | 栈 | 字重 |
|---|---|---|
| 数字/标题（display） | `"Kaiti SC","STKaiti","KaiTi","Noto Serif CJK SC",serif` | 800-900 |
| 正文 | `"Songti SC","STSong","Noto Serif CJK SC","SimSun",serif` | 400-600 |

- 楷体数字是 C 的识别度来源（绘本手写感）；HUD 大数字必须加 `font-variant-numeric: tabular-nums`，等宽对齐优先于字形
- Android 无 KaiTi 时降级 Noto Serif CJK；PWA 可内置楷体子集（标题常用约 500 字，预算 ≤400KB）
- 小字号（≤11px）不用衬线：角标、耐久牌、数量牌一律系统无衬线 900
- 阶梯（460px 竖屏基准）：HUD 数字 22-26 / HUD 标签 10-11 / 弹窗标题 18-20 / 面板副题 14 / 正文 13-14 / 按钮 15-16 / 角标 9-11

## 3. 形状与边缘语言

- 圆角按层级递减：弹窗 16 / 卡片·HUD 芯片 12 / 按钮 10 / 棋盘 12 / 格 8 / 物品 6
- **衬纸边是 C 的签名**：所有浮起元素（物品 tile / HUD 芯片 / 按钮 / 棋盘）= `0 0 0 3px #FFFFFF, 0 0 0 4px rgba(79,66,53,.14)` 两层 box-shadow（白纸边 + 炭铅细圈），叠淡彩影 `0 3px 8px rgba(199,122,90,.14)`
- 手绘感来自 SVG 内部描边（炭铅 `#B98A5E`，可变宽 1.2→2px），不来自 CSS 变形；**棋盘物品禁止 rotate 倾斜**（扫读性铁律，沿袭项目既有决议）
- 深档链色上的描边换浅墨 `#F2DDB4`，避免糊在一起
- 纸纹颗粒仅用于文档与装饰面（静态 CSS 点阵 7px 网格、ink 5.5%）；棋盘与贴图运行时零纹理滤镜

## 4. 贴图生产管线（双版本）

### 4.1 分工

| 版本 | 内容 | 交付时机 |
|---|---|---|
| SVG v1（立即可用） | 干净几何 + ≤3 stop 平涂浸染 + 炭铅描边 + 高光/暗部两档（lite 0.72 / shade 0.55） | M1 试点 |
| webp v2（试点验证后） | 在 SVG 几何上离线烘焙湿边（边缘位移 + 纸纹颗粒） | M3 铺开 |

### 4.2 铁律

- 运行时禁 `feTurbulence` / `feDisplacementMap`（对比样张里 C 列的位移滤镜只是文档演示，**不进游戏**）
- 资源键契约：webp 与 svg **不得同名并存**（`src/ui/sprites.ts` 的 glob 会撞键）。替换 = 先删 `.svg` 再放同名 `.webp`，游戏代码零改动
- 尺寸基准：48px 画布、@2x 输出 96px、单文件 webp ≤10KB
- 母体/中段发射器的状态描边走 CSS 类（`.gen` 实线 / `.mid` 虚线），SVG 本体不含任何状态标记

### 4.3 单张 QA 清单（9 项）

① 48px 下可辨形 ② 描边闭合无断口 ③ 高光位一致（左上）④ 暗部位一致（右下）⑤ 浸染档位正确 ⑥ 中段发射器无内部耐久标记 ⑦ 顶点标记（小旗/皇冠）仅 Lv8 ⑧ webp 与 svg 视觉差 ≤5% ⑨ 文件 ≤10KB

## 5. 等级递进表达法（链内 Lv1→Lv8）

等级信号由贴图本体承担（tile 底色不再表达等级，避免「满屏深浅块」干扰扫读），四个变量同步递增：

1. **浸染档位**：Lv1-2 用浅档、Lv3-5 用中档、Lv6-8 用深档（§1.4）
2. **部件密度**：Lv1 ≤3 件；Lv4 起加装饰件（蝴蝶结/波点）；Lv8 ≥7 件 + 顶点标记
3. **墨线粗细**：Lv1-2 为 1.2px 浅墨、Lv5-6 为 1.6px、Lv7-8 为 2px 深墨
4. **tile 内占比**：Lv1 64% → Lv8 78%，高等级「更满」

## 7. 动效规范

- 只碰 `transform` / `opacity`（项目铁律）；禁 filter 过渡、禁 backdrop-filter 动画
- 合成反馈沿用现有 pop/land 时长（0.2-0.34s）；C 不加发光脉冲——「可领补贴」提示改为纸边呼吸（opacity 0.6↔1，1.6s）
- 飞行物品抛物线 + 落地回弹参数不变；屏幕震动沿用 `--shk` 常量

## 8. 性能预算（中低端安卓 60fps 为合格线）

1. 运行时 SVG 滤镜：0（铁律）
2. 全屏合成层：0（铁律，沿袭项目既有决议）
3. 同屏贴图 ≤63（棋盘满负荷）+ 弹窗 ≤12；webp 有解码缓存，SVG v1 无位图内存
4. 纸纹颗粒仅装饰面；棋盘格零纹理
5. 降级线：fps<50 时关纸纹颗粒、纸边 3px→2px、粒子减半（接现有 FxCanvas 参数出口）

## 9. 落地路线图

- **M0 令牌落地**：本文档 + `src/style.css` 的手绘贴纸换肤层整体替换为 C 层（沿用 `--surface/--ink` 命名空间，旧层删除、不留双轨）
- **M1 试点（先做这个）**：玩具链 8 张（SVG v1 + webp v2）+ 中端安卓真机 fps 抽检（≥55fps 为通过）
- **M2 复审**：严过审 5 维复审试点产物 + 「一眼辨链」测试（玩具/护理/食物/设施四链同屏盲测）
