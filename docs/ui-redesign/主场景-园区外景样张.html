交互规格（实现时按此落地）

  1. 平移：单指拖拽空白处移动镜头，松手无惯性；边界限制沿用现有 clampCam。拖拽位移 > 4px 时不触发点击（现有 moved 判定直接复用）。
  2. 点已建建筑：底部滑出信息卡（120ms 上滑 + 淡入）；点空白处 / × / 再点同一建筑 → 收起。
  3. 点告示牌：弹出购地确认卡；星星不足时「确认扩建」置灰并显示「还差 ⭐N」。
  4. 长按建筑 400ms：进入装饰摆放模式（拖拽移动、点旋转、点空白退出）。装饰只花星星，不产出。
  5. 进入棋盘：底部深色主按钮是唯一入口，与现有 store.enterBoard() 一致。
  6. 层级：场景 < 信息卡 < 弹窗；信息卡出现时 HUD 与底部栏保持可见（不遮主入口）。
  7. 性能：场景用 Canvas 绘制（沿用现有 YardView 结构），建筑贴图走 src/assets/sprites/regions/ 资源键；信息卡用 DOM。禁止在 Canvas 里画文字排版（现有 emoji + 文字标签方案在 C 风格下不成立，改为「贴图 + DOM 标签」）。

与现状的差异：现在 YardView.vue 用 Canvas 画斜视草地 + emoji 建筑 + 黄牌价格，顶部只有「存档 / ⭐ / 猫狗」，底部「进入棋盘 / 图鉴 / 活动」。本样张把建筑换成 C 水彩建筑贴图，把「点建筑直接升级/进棋盘」改成先出信息卡再选择——避免误触直接进棋盘，也让「升级 / 进入 / 装饰」三个动作各有明确入口。

素材需求：9 个区域建筑各 2-3 级造型（区域贴图目录已有 region-*.svg 占位），加 4 个通用件（告示牌 / 树 / 路灯 / 长椅）。全部按 C 的炭铅描边 + 淡彩画法绘制。
