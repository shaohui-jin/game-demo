## A 方案关键细则（备录）

- 发光上限 18%、单屏 ≤2 处发光；取消白边硬切割，改"模切外发光轮廓"
- 色板彩度双轨：场景/框架低饱和铺，可交互元素高饱和跳
- 数字字体变量 `--font-num` 建议用 Baloo 2 / Nunito 网络字体 SVG 化后置本地 sprite 目录
- 性能：禁全屏 mix-blend 合成层；粒子走 WebGL/Canvas 离屏合成
- SVG 贴图走 C 方案的"路线 1：SVG 三阶体积光渲染"（色阶文本化：暗部 pow(基色,0.82)/固有色/高光 mix(#fff,基色,0.82)，画布 ≤64×64）

## B 方案关键细则（备录）

- 玻璃拟态 HUD：rgba(255,255,255,0.75) + 3px 内描边 #FFEDE3 + 0 模糊硬落影
- 弹跳/按压/开关/出场四组弹性曲线（cubic-bezier 0.34,1.56,0.64,1 一族）
- CTA 三条铁律：渐变必现 / 高光扫过 2s / 按压必弹
- Leaflet 式不动点缩放，面包屑放订单页；底部滚动作导航栏置后
- 触热区 ≥48dp 必须满足拇指法则

## C 方案关键细则（备录）

- 三条落地路线：路线1 高质量 SVG 三阶体积光渲染（推荐，兼顾性能与统一）；路线2 预渲染位图 sprite sheet；路线3 Lottie/Rive 轻量骨骼（动画旗舰）
- 妖兽/生物用 SVG feTurbulence 轻颗粒噪声；UI 面板用低透明度噪点 CSS 层
- 三级冷白瓷三阶阴影（大/中/小），水彩边框"渗色" 1px 内发光
- 字体大落差（44px display/20px title/12px bar）+ 排版网格留白 ≥64px 优良
- 风险：水彩横幅复用、SVG feTurbulence 性能、渲染稳定性——需提前压测
