# 爪爪乐园 · 现状

> 2026-10-11。做了什么、没做什么只维护这一份。
> 玩法规格在 `爪爪乐园-游戏设计方案.html`。对标机制在 `肥鹅健身房-玩法机制拆解.html`。界面和贴图在 `爪爪乐园-UI视觉稿.html`、`爪爪乐园-全造型一览.html`。

工程：Vue 3 + TypeScript + Pinia。`npm test`。旧档按缺字段补默认值，不升存档版本。

## 已实现

**合成。** 63 格棋盘、二合一、甲·重置为满。10 条链：设施 5 级，礼包 4 级，玩具 / 护理 / 食物 / 舒适 / 训练 / 医疗 / 清洁 / 货币各 8 级。中段发射器在 Lv3 和 Lv6。设施含点击型和自动型。母体三种耗尽。

**道具。** 剪刀、升级卡、充能器、加速沙漏、绿 / 蓝 / 紫能量球（30 / 50 / 80 体力）、无限能量（5 分钟点击不耗体力）。

**体力、蛛网、背包。** 背包在棋盘上，金币扩容。每天领 1 个玩具架。

**订单。** 2 槽 4 档，到期重抽。可以放弃，同一链同一等级 10 分钟内不再出现。雨天护理订单金币翻倍。节日期间订单金币 +20%。

**顾客与宠物。** 24 只，各 3 幕剧情，好感 80 / 160 / 240 解锁。满好感变常驻宠物。宠物可派到区域，猫狗同区触发羁绊并产出物品。常驻宠物可以代打设施 5 次，不耗玩家体力。

**区域与装饰。** 9 个区域依次解锁，并开放对应的链。11 件装饰只花星星。乐园里可以摆放、旋转，三套方案。摄影棚可导出明信片。

**图鉴、造型、卡牌。** 元素 / 装饰 / 顾客收集度。24 件造型，抽奖第一次给实物，重复才折成钻石。故事卡在第二幕解锁。

**商城与模拟充值。** 金币不出售。充值只加钻石。会员、基金、礼包、抽奖。

**活动。** 9 个节日。可以时间旅行到某一档，也可以回到今天。每日任务和签到。

**开局。** 先进入乐园。12 块地按顺序用星星买下（20–48 星，前台免费）。建筑打开对应的链，或者只换样子，没有生产倒计时。猫和狗是设置里的外观，不分开两套进度。棋盘左下角返回乐园。然后提示备份一次。

**存档。** 迁移、校验、3 槽备份、导入导出。设置里有游玩统计、音效开关、乐园布局分享码。网页可安装（`manifest.webmanifest`）。合成音效用振荡器现做，默认关闭。

## 还没做

- 安卓 APK。这台环境没有 Android 构建工具，没有打出安装包。网页版用 `npm run build`，浏览器里可以「添加到主屏幕」。
- 造型和链的新等级没有单独画贴图，缺图时用 emoji。
- 节日没有独立的限时棋盘，收益是订单金币和一份每日礼物。
