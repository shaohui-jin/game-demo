# 第六批 · 交互修正（2026-10-02）

用户实测后提出 4 条交互修正，本批全部落地。**232/232 测试绿 + vue-tsc 干净 + 生产构建通过**。

## 1. 拖到占用格：挤出 / 换位规则

原行为：拖到被占用且不可合成的格子 = 纹丝不动（hint 为 null，drop 无操作）。

新规则（`logic.ts` 纯函数 `findDisplaceCell`，store 集成 `displaceDrop`）：

1. 原物品被挤到**周围 8 格**中的随机空位（环 1，切比雪夫距离恰为 1）；
2. 环 1 全满 → 挤到**再外一圈**（5×5 环）的随机空位；
3. 全盘无空位 → 两个物品**换位**（返回 `'swap'` 信号，from/to 互换）。

硬约束：
- **蛛网格不算空位**（蛛网只能花钱清或牺牲换，不能被免费挤掉）；
- **背包格不算空位、也不可作为挤出目标**（背包是常驻道具，不可被挤走）；
- 棋盘边缘环搜索自动裁剪越界格；
- 蛛网牺牲 / 空格移动 / 同链合成在 `GameBoard.onDrop` 里先行分流，不经过挤出逻辑。

UI：新增拖拽提示 `.cell.displace`（橙色虚线环）——明确告诉玩家"松手会把它挤开"。

## 2. 背包弹窗居中悬浮（不再挤压主场景）

原行为：底部抽屉占 46vh，打开时把棋盘往上压（`--bag-h` CSS 变量那一套）。

新行为：点背包 = **居中悬浮弹窗**（`.modal > .card.bag-card`，与其他弹窗同骨架），棋盘纹丝不动。

- `BackpackDrawer.vue` 已删除，替代为 `BackpackModal.vue`；
- `--bag-h` / `bag-open` / `.bagdrawer` / `.bd-*` 样式全部拆除；
- `.board` 宽度公式里的 `var(--bag-h)` 项移除；
- 弹窗内点击物品 = **直接放回主场景**（随机空位 + 飞行动画，`takeFromBag` 语义不变）；
- 点击特殊道具 = 进入待用态 / 直接生效（`beginToolUse` 保留，target 类道具必须有目标）。

## 3. 背包是摆在主场景上的道具

架构决策：**背包不进 `board` 物品数组**（不污染 `BoardItem` 类型与链体系），
用新字段 **`s.bagAt: number`** 表示背包所占棋盘格（-1 = 暂不在盘上，走信息栏入口）。

- 默认右下角 `TOTAL - 1`（62）；新档 `freshState` 即设置；
- **占格但不是 BoardItem**：不参与合成 / 订单 / 蛛网 / 图鉴；
- 点它 = 打开弹窗；**拖它** = 挪位（`moveBagTo`：只能落到非蛛网空格）；
- **物品拖到背包格** = 存入（复用 `moveToBag`：冻结 + 冷却挂起不变）；
- 交互铁律相应更新："拖到背包"从抽屉交互变为棋盘格交互，
  拖拽落点 zone 从 `'bag'`（抽屉格）改为 `'bag-cell'`（棋盘上的背包格）。

旧存档兼容（**不升 SAVE_VERSION**，可加字段 + 默认值）：
- `normalize()` 里 `bagAt` 非法（缺失 / 越界 / 指向被占或蛛网格）→ `placeBag(s, TOTAL-1)` 补齐；
- `placeBag` 目标被物品占着 → 把原物品挤到随机空位；全盘无空位 → `bagAt = -1`；
- `placeBag` 只在初始化 / 归一化调用，运行中背包只被玩家拖动。

牵连的"空格语义"全部排除背包格：
`pickRandomEmpty`（加可选参 `bagAt`，全 store 调用点已传）、`countEmpty`、`addWeb`（蛛网永不盖背包）、`reconcileWebs`（兜底清掉盖在背包上的蛛网）、`seedBoard` / `ensureFacilities` / `tickAuto`。

## 4. 全局无滚动条 + 拖拽拿起手势

- **全局隐藏滚动条**（`* { scrollbar-width: none }` + `::-webkit-scrollbar { display: none }`）：
  内容仍可滚动（弹窗长内容、背包网格），只是不显示滚动条——移动端手势滚动；
- `html, body { overflow: hidden; height: 100% }` 锁定整页；
- **拿起手势**：`useDrag` 的 transform 从 `scale(1.12)` 升级为
  `scale(1.12) rotate(-2.5deg)`（**固定**角度，不是随机——遵守"不给带文字元素随机倾斜"铁律，
  这是松手即消失的手势动画，与 flyer 自旋同类豁免）；
- CSS 侧 `.item.dragging`：落影加深放大 + 轻微提亮 + `z-index: 30` —— "被捏起来"的层次感；
- 拖拽落点提示环全部改为 **outline**（铁律：box-shadow 位留给贴纸落影），
  旧 `.cell.ok/.merge/.websac` 的 inset box-shadow 顺手迁移。
