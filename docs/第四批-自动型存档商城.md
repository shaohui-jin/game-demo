> 2026-10-02 完成。对应《功能模块排期.md》的 M1（自动型）、M5（存档契约）、M2 核心（商城）。
> **本批 185 个测试全绿（`npx vitest run`），`vue-tsc --noEmit` 通过。**

## 01 自动型发射器（M1）

设施链从 3 级扩到 **5 级**：玩具架 → 玩具箱 → 玩具仓库（点击型）→ **逗猫转盘** → **自动喂食器**（自动型）。

- `AutoSpec { ms, drops, max }`，`ItemKind` 新增 `'auto'`，`isAutoDef()` 收窄类型。
- `tickAuto(s, now, rng)`：每秒 tick（`tickBusiness` 步骤③）驱动，规则：
  1. **累积上限**：`cycles >= cap`（默认 `AUTO_ACCUM_MAX = 8`）时 `lastAutoAt = now`，多余次数作废（防止离线挂机囤积）；
  2. **棋盘满不吞次数**：可能产出物品但无空位时，不推进时间戳、不消耗；
  3. **周期对齐**：结算后 `lastAutoAt = last + n×ms`，不足一个周期的余量保留到下一轮。
- 自动型无储备徽标、不可点击，棋盘上带 `⟳` 角标（`BoardCell`）。
- 链路图鉴节点带 `自动 · 每 Ns` 标注（`ChainTreeModal`）。

## 02 存档契约（M5）

`SaveEnvelope { schemaVersion, savedAt, deviceId, checksum, payload }`：

- `checksumOf` = djb2 → base36，校验失败视为"数据不完整"→ 交给备份链；
- `unwrapSave()` 兼容旧版裸 state（无信封）；
- **3 个轮转备份槽**：`backupNow()`（1→2→3）、`listBackups()`、`restoreBackup()`；
- 导出/导入：`exportSaveText()` / `importSaveText()`（走 `normalize()`，坏数据只清它自己）；
- `load()` 降级链：主存档 → 3 备份（新→旧，带 `fromBackup` 标记）→ P0 legacy；
- `SettingsModal.vue`：存档状态、3 槽位备份（恢复需确认）、立即备份、导出到剪贴板、textarea 导入、重置（保留备份）；
- `init()` 每日自动备份一次（`bakDay`）。

## 03 商城（M2 核心）

`src/game/shop.ts`：9 件商品。

- **红线**：没有任何"钻石换金币"的商品（文档 15 章风险项，有测试锁定）；
- **金币区不限购**（5 件：材料箱×3 / 沙漏 / 剪刀），**钻石区必须限购**（4 件：体力 3 / 充能器 3 / 能量球 3 / 设施 1）；

- `ShopModal.vue` 金币/钻石两个分区，每件商品显示余量/售罄/等级锁。

## 04 本批抓出的 3 个真实 bug（测试回归的成果）

1. **★ 导入存档后整份存档变砖**（logic.test.ts 抓出）：`importSaveText()` 把 `parsed` 原样写回，但 `normalize(state)` 是**就地修改** state（== `parsed.payload`），写回时 payload 已是"修过的"，`checksum` 却是"修前"的 → 下次 `load()` 校验必失配 → 主存档被丢进备份链 → 导入后返回 null。**修复**：写回走 `wrapSave(res.state)` 重新算 checksum。
2. **材料箱"按实收扣费"被自己的门槛挡死**（game.test.ts 抓出）：`needsBoardSpace: 3` 硬校验在"只剩 1 个空位"时整单拒绝，prorate 分支永不可达。**修复**：crate 类只要求 ≥1 空位（能放几个放几个），设施类保持足额校验。
3. **测试环境 runner 崩溃**：vitest 5.0.3 + vite 8.3.1 下默认 `forks` 池报 `Vitest failed to find the runner`、`threads` 池报 `Cannot read properties of undefined (reading 'config')`，最小空测试即复现，与 node 22/24、jsdom、配置文件均无关；**`vmThreads` 池完全正常**，已固化进 `vite.config.ts`（`pool: 'vmThreads'`）。forks 池独立子进程在本机 3.89 GB 内存下也经常被 OOM。

另有 4 处测试断言没跟上新行为，已同步更新（图鉴 3→5 节点、开局送 1 个充能器、自动型周期对齐断言、材料箱测试固定蛛网随机性）。
